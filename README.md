
# Healthcare SQL Hospital Management Analysis

## Project Overview

This project analyzes hospital admissions data using SQL to evaluate patient volume, treatment costs, readmissions, length of stay (LOS), and resource utilization.

The objective was to answer key hospital management questions and transform raw healthcare data into actionable business insights.

## Business Questions

* How many admissions occurred during the study period?
* How many unique patients were treated?
* What was the most common diagnosis?
* Which department handled the highest patient volume?
* Who generated the highest treatment cost?
* What was the average treatment cost?
* How many elderly patients experienced repeated admissions?
* What was the average length of stay?
* Which diagnosis generated the highest cost per day?

## Tools Used

* PostgreSQL
* SQL
* CSV Dataset
* GitHub

## Key Results

* 50 Total Admissions
* 18 Unique Patients
* Essential Hypertension was the most common diagnosis
* Cardiology was the busiest department
* 6 Elderly Patients experienced repeated admissions
* Acute Appendicitis generated the highest average cost per day
* Average Length of Stay: 4.26 Days
